# Usage data stays in the browser, without reply content

The extension reads every reply a user streams, so it must be trusted not to keep or send it. Usage data lives in `storage.local` only, with no server, account, telemetry or network call of its own; it leaves the browser only through the CSV and JSON exports the user asks for. Reply text reaches the background only to be counted and is never stored: an event keeps metadata (provider, models, token count, latency, estimate, flags). To bound storage the event log keeps the latest 500 replies and longer periods come from daily aggregates, so per-reply detail is lost beyond the log.
