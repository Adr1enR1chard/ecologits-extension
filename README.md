# EcoLogits Extension

Cross-browser extension (Chrome, Firefox, Edge, Safari) that estimates the environmental impact (energy, GHG emissions, etc.) of your generative AI usage, powered by [EcoLogits](https://ecologits.ai).

## Supported providers

- OpenAI (ChatGPT)
- Anthropic (Claude)
- Google (Gemini)
